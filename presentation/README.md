# Remotion projekt

Izvor prezentacije koristi snimke stvarne lokalne aplikacije iz `public/screens/`.

## Render

```sh
npm install
npm run render -- --concurrency=2
```

Za svježe snimke najprije pokrenite aplikaciju na `http://127.0.0.1:8080/`, a zatim izvršite `node tools/capture-app-screens.mjs`.
